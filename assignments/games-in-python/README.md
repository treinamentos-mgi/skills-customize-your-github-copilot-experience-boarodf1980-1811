
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo da Forca em Python, praticando manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️ Selecionar e Exibir a Palavra

#### Descrição
Escolha uma palavra aleatória e mostre o progresso oculto para o jogador.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Exibir o progresso atual no formato `_ _ _`, substituindo `_` pelas letras já adivinhadas


### 🛠️ Receber Palpites e Controlar Tentativas

#### Descrição
Permita que o jogador digite letras e controle quantas tentativas incorretas ainda restam.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras digitados pelo usuário
- Rastrear o número de tentativas incorretas restantes


### 🛠️ Encerrar a Partida

#### Descrição
Finalize o jogo quando a palavra for descoberta ou as tentativas acabarem.

#### Requisitos
O programa concluído deve:

- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem
- Exibir mensagem de vitória ou de derrota
